# Art, Audio, and Assets

This directory houses all the media files for Project HAU. Our visual identity is rooted in charming, retro 2D pixel art that brings the university campus to life.

## The `drafts/` Folder
Not sure if a sprite looks right? Drop it in the `assets/drafts/` folder. This is our sandbox for rough sketches, WIP pixel art animations, tileset tests, and temporary sound effects. Files here do not need to follow strict naming conventions.

## Aesthetic Goals
* **Visual Style:** 2D Pixel Art (Top-down or isometric perspective).
* **Environment:** Accurately reflecting the vibe of the Holy Angel University campus.
* **Audio:** Upbeat, nostalgic chiptune or lofi tracks, paired with ambient campus sounds.

## Production File Naming Conventions
Once an asset is finalized and moved out of `drafts/`, it must follow this structure:
`[AssetType]_[Name]_[State].[extension]`
* **Example:** `spr_student_walk_down.png`
* **Example:** `tile_computing_building_wall.png`
* **Example:** `sfx_quest_complete.wav`

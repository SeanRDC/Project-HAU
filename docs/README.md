# Game Design & Documentation

Welcome to the brain-dump zone. This folder is dedicated to mapping out the campus, designing quests, and structuring the game before we commit to the final code.

## Current Objectives
* Finalize the layout of the in-game campus map.
* Draft the first 3 introductory quests.
* Outline the dialogue system requirements.

## The `drafts/` Folder
If you have an idea for a cool quest or a campus secret, pitch it here! 
1. Create a Markdown (`.md`) file in the `drafts/` subfolder.
2. Title it clearly (e.g., `quest_find_lost_usb.md` or `npc_cafeteria_vendor.md`).
3. Outline the idea and bring it up in our next team sync.

## Master Documents (Coming Soon)
Approved ideas will be moved to the main directory to form our official Game Design Document (GDD) and Quest Log.
